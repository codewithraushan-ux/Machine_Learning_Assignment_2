## Files

## Run

Use Python 3.11 as a setup option. From the folder containing the notebooks and `requirements.txt`:

```bash
python -m pip install -r requirements.txt
jupyter notebook
```

Open `1.ipynb`, `2.ipynb` and `3.ipynb` in order. Each runs independently. Restart its kernel, run all cells and save the outputs.
